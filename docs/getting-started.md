# Getting Started with MeshWhisper

This guide takes you from zero to a working PWA with end-to-end encrypted messaging. Follow every step in order.

**What you will have at the end:**
- A MeshWhisper Node running on your server behind TLS
- A PWA that can send and receive encrypted messages
- Push notifications that wake the app when a message arrives while it is closed

**Time required:** approximately 30–60 minutes.

---

## Prerequisites

- A server with Docker and Docker Compose installed (any VPS — 1 CPU, 512MB RAM is sufficient)
- A domain name with DNS pointed at that server (e.g. `relay.myapp.com`)
- Node.js 18+ on your development machine
- An npm account at npmjs.com (free)
- A web browser that supports Web Push (Chrome, Firefox, Edge, Safari 16.4+)

---

## Step 1 — Scaffold your project

On your development machine, create a new project directory and run the MeshWhisper CLI:

```bash
mkdir my-chat-app && cd my-chat-app
npm init -y
npx @meshwhisper/cli init
```

The CLI will ask two questions:

1. **App bundle ID** — use reverse-domain format, e.g. `com.example.mychatapp`
2. **Node** — enter `self-hosted`, then enter your Node URL: `wss://relay.myapp.com`

The CLI outputs:
- A `.env` block with a generated developer key and salt — copy these into a `.env` file
- An SDK init code snippet — you will use this in Step 4
- A `docker-compose.yml` — you will use this in Step 2

Your `.env` file should look like this:

```bash
MESHWHISPER_DEVELOPER_KEY=<generated value>
MESHWHISPER_SALT=<generated value>
MESHWHISPER_NODE_URL=wss://relay.myapp.com
```

**Do not commit `.env` to git.**

---

## Step 2 — Deploy the Node relay

### 2a — Generate VAPID keys for Web Push

On your development machine:

```bash
npx web-push generate-vapid-keys
```

Copy the output. You will need both keys in the next step and the **public key** in your PWA code.

### 2b — Configure the server

Copy `docker-compose.yml` to your server, then create a `.env` file alongside it:

```bash
VAPID_PUBLIC_KEY=<your public key>
VAPID_PRIVATE_KEY=<your private key>
VAPID_SUBJECT=mailto:you@example.com
```

The `docker-compose.yml` generated by the CLI already has the correct structure. Open it and verify `BASE_URL` matches your domain:

```yaml
services:
  node:
    environment:
      BASE_URL: "https://relay.myapp.com"   # ← must match your domain exactly
      PUSH_WEBHOOK_URL: "http://push:4000/notify"
  push:
    environment:
      VAPID_PUBLIC_KEY: "${VAPID_PUBLIC_KEY}"
      VAPID_PRIVATE_KEY: "${VAPID_PRIVATE_KEY}"
      VAPID_SUBJECT: "${VAPID_SUBJECT}"
```

### 2c — Set up a reverse proxy

The Node listens on port 8080 over plain HTTP. Your reverse proxy handles TLS.

**Caddy** (recommended — handles TLS certificates automatically):

Create `/etc/caddy/Caddyfile` on your server:

```
relay.myapp.com {
    reverse_proxy localhost:8080
}
```

Then:
```bash
sudo systemctl reload caddy
```

**nginx** — see `docs/self-hosting.md` for the full nginx config.

### 2d — Start the services

On your server:

```bash
docker compose up -d
```

Verify it is running:

```bash
curl https://relay.myapp.com/health
```

Expected response:
```json
{"status":"ok","clients":0,"storedBlobs":0,"prekeyEntries":0,"pushRegistrations":0,"mediaEntries":0}
```

If you get a connection error, check `docker compose logs` for startup errors.

## Step 3 — Set up the service worker

The service worker handles push events when your PWA is closed.

Install the package:

```bash
npm install @meshwhisper/sdk @meshwhisper/service-worker
```

Copy the built service worker file into your project's public directory:

```bash
cp node_modules/@meshwhisper/service-worker/dist/meshwhisper-sw.js public/
```

This file must be served from the **root** of your domain (e.g. `https://myapp.com/meshwhisper-sw.js`) for push notifications to work. If your public directory is named differently (`static/`, `www/`, etc.) adjust the path accordingly.

## Step 4 — Integrate the SDK into your PWA

Install the SDK if you haven't already:

```bash
npm install @meshwhisper/sdk
```

Create `src/messaging.ts` (or `.js`):

```ts
import { MeshWhisper } from '@meshwhisper/sdk';
import type { WebPushSubscription } from '@meshwhisper/sdk';

const VAPID_PUBLIC_KEY = 'your-vapid-public-key-here';  // from Step 2a
const NODE_URL = 'wss://relay.myapp.com';               // your Node URL
const NAMESPACE = 'com.example.mychatapp';              // your bundle ID from Step 1

// Convert VAPID public key to the format pushManager.subscribe() expects
function urlBase64ToUint8Array(base64String: string): Uint8Array {
  const padding = '='.repeat((4 - (base64String.length % 4)) % 4);
  const base64 = (base64String + padding).replace(/-/g, '+').replace(/_/g, '/');
  const raw = atob(base64);
  return Uint8Array.from(raw, (c) => c.charCodeAt(0));
}

export async function initMessaging(
  onMessage: (senderId: string, text: string) => void,
  onStatusChange: (messageId: string, status: string) => void,
) {
  // 1. Register service worker
  const registration = await navigator.serviceWorker.register('/meshwhisper-sw.js');

  // 2. Subscribe to Web Push
  const subscription = await registration.pushManager.subscribe({
    userVisibleOnly: true,
    applicationServerKey: urlBase64ToUint8Array(VAPID_PUBLIC_KEY),
  });

  // 3. Initialize SDK — auto-detects browser, uses IDBStorage + BrowserTransport
  const mw = await MeshWhisper.init({
    namespace: NAMESPACE,
    node: NODE_URL,
    push: {
      platform: 'webpush',
      subscription: subscription.toJSON() as WebPushSubscription,
    },
    onMessage: async (message) => {
      // Check if it's a media message
      const media = await MeshWhisper.downloadMedia(message);
      if (media) {
        // Handle media — message.payload contains { url, key, mimeType }
        console.log('Received media message from', message.senderId);
        return;
      }

      // Plain text message
      const text = new TextDecoder().decode(new Uint8Array(message.payload));
      onMessage(message.senderId, text);

      // Mark as read
      await MeshWhisper.markRead(message.id, message.senderId);
    },
    onMessageStatus: (messageId, status) => {
      onStatusChange(messageId, status);
    },
    onPresence: (peerId, status) => {
      console.log(`${peerId} is ${status}`);
    },
  });

  return mw;
}

// Get your peer ID to share with contacts
export function getMyId(): string {
  return MeshWhisper.instance.getLocalPeerId();
}

// Send a text message
export async function sendMessage(recipientId: string, text: string): Promise<void> {
  await MeshWhisper.send(recipientId, new TextEncoder().encode(text));
}

// Send a file
export async function sendFile(recipientId: string, file: File): Promise<void> {
  const bytes = new Uint8Array(await file.arrayBuffer());
  await MeshWhisper.sendMedia(recipientId, bytes, { mimeType: file.type });
}

// Load message history for a conversation
export async function loadHistory(peerId: string) {
  return MeshWhisper.getMessages(peerId, { limit: 50 });
}
```

### Usage in your app

```ts
import { initMessaging, getMyId, sendMessage } from './messaging';

// On app load
const mw = await initMessaging(
  (senderId, text) => appendMessage({ from: senderId, text }),
  (messageId, status) => updateTick(messageId, status),
);

// Show your peer ID so contacts can add you
document.getElementById('my-id').textContent = getMyId();

// Send a message when the user hits send
document.getElementById('send-btn').addEventListener('click', async () => {
  const recipientId = document.getElementById('recipient-id').value;
  const text = document.getElementById('message-input').value;
  await sendMessage(recipientId, text);
});
```

## Step 5 — Test it

Open your PWA in **two different browsers** (or two devices). Copy the peer ID from one and paste it as the recipient in the other.

Send a message. It should appear in the other browser within a second or two.

To test offline push delivery:
1. Close one browser tab completely
2. Send a message from the other
3. The closed tab's browser should show a "New message" notification
4. Click the notification — the app opens and the message appears

## Common problems

**Messages not delivering**

- Check `docker compose logs node` for errors
- Verify `BASE_URL` in your `docker-compose.yml` matches your public domain exactly — no trailing slash
- Verify the WebSocket URL in your SDK config starts with `wss://` not `ws://`

**Push notifications not arriving**

- Check `docker compose logs push` for errors
- Verify `VAPID_PUBLIC_KEY` in your PWA code exactly matches `VAPID_PUBLIC_KEY` in your server `.env`
- Verify the service worker is being served from the root of your domain — open `https://myapp.com/meshwhisper-sw.js` in a browser and confirm it loads

**"NotAllowedError" when subscribing to push**

- The page must be served over HTTPS for `pushManager.subscribe()` to work
- The user must have granted notification permission — call `Notification.requestPermission()` first

**Identity resets on every page load**

- This means `IDBStorage` is not persisting — check that your site is not in private/incognito mode, which blocks IndexedDB writes in some browsers
- Check browser console for IndexedDB errors

**`npm install @meshwhisper/sdk` fails**

- Requires Node.js 18 or higher — run `node --version` to check
